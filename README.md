# 最后一炮DDS贴图还原工具  FinalFire_DDS_Texture_Restorer

“最后一炮”这个游戏的文件夹里有许多dds贴图不能被photoshop打开，即使photoshop已经装了dds插件，所以需要此工具还原一下才行
In the "FinalFire" game folder, a lot of DDS textures can't be opened in Photoshop, even though Photoshop has a DDS plugin installed, so you need this tool to restore them.

# 下载  Download

在release那里下载exe格式的文件，一个带GUI，一个不带，看文件名就能知道，这两个版本使用方法不一样
Download the exe files from the release section, one with a GUI and one without, you can tell just by looking at the file name.

# 使用方法 How to use

GUI版本下载好后双击打开选择有需要还原的dds贴图的文件夹，还原好后，exe文件所在的目录会出现一个fixed文件夹，还原好的dds贴图在这里面
After downloading the GUI version, double-click to open it and select the folder containing the DDS textures you need to restore. Once restored, a 'fixed' folder will appear in the directory where the EXE file is, and the restored DDS textures will be inside.

没有GUI的版本则需要把exe文件放到需要还原的dds贴图的文件夹，双击exe文件，然后就会出现一个fixed文件夹，还原好的dds贴图就在里面
The version without a GUI requires you to put the exe file into the folder with the DDS textures you want to restore, double-click the exe file, and then a 'fixed' folder will appear. The restored DDS textures will be inside.
